Your file is never uploaded

    

      This is a tool for finding leaked credentials. Asking you to upload the file
      containing those credentials would be a strange way to build it, so it does
      not. The checker is the real Python linter, compiled to WebAssembly and run
      inside this tab.

      Full disclosure on what does load: opening the page fetches this page's
      own files and the Pyodide runtime from the jsDelivr CDN, the same way any site
      loads a script. That happens before you choose a file and never includes your
      workflow. There is no server, no database, no analytics, and no log of what you
      checked — which also means nobody, including us, can see your results.
    

  


  
  

    
What it checks

    

    

      Every rule is measured against 59 real published workflows before it ships. A
      linter that cries wolf gets switched off, so a warning firing on more than
      two-thirds of that corpus is treated as an opinion rather than a defect and
      gets downgraded — one of these rules failed that bar and was demoted.
      See the calibration data.

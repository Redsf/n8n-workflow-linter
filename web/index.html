    The file is not uploaded
    
        
    
          This tool exists to find credentials people left inside workflow files.
          Asking you to send that file to a server would be a strange way to build
          it, so there is no server. The checker is the real Python linter compiled
          to WebAssembly, running inside this tab.
        
    
        
    
          There is no account, no database, no analytics, and no record of what you
          checked. That also means nobody, including the author, can see your
          results.

          either.
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    What gets checked
    
      
    
      
    
        Every rule is measured against 59 real published workflows before it ships.
        A linter that cries wolf gets switched off, so a warning that fires on more
        than two thirds of that set is treated as an opinion rather than a defect
        and gets demoted. One rule failed that bar and was demoted to a note.
        Read the calibration data.
